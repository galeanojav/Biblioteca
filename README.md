# Biblioteca de casa

Catálogo de mis libros con el estante donde está cada uno.

- **Consulta:** abre `index.html` (o la página de GitHub Pages de este repositorio).
- **Datos:** `biblioteca.json` (completo, por estantes).

## Códigos de estante

- Buhardilla: `BUH-C<columna>-B<balda>`. Columnas de izquierda a derecha desde la entrada y baldas de arriba abajo.
- Salón: `SAL-B<balda>`. Despacho: `DES-B<balda>`.

## Clasificación

Bloque (género real del libro) › ámbito › país (nacionalidad del autor).

La versión editable está en Claude. Este repositorio es una copia pública que se actualiza periódicamente. No incluye los préstamos.
